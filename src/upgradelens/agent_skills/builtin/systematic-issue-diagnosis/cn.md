# 系统化问题诊断

最昂贵的修复是修错了方向。本技能强制智能体在动代码之前先理解失败。

## 工作流

1. **定位。** 把症状钉死在具体位置与触发条件上。含糊的“它会崩”不算诊断。
2. **广泛假设。** 列出多种机制，第一个想法往往很浅。
3. **用证据检验假设。** 阅读代码路径、做针对性检查或检索相关文档，记录每条
   机制被确认或排除的依据。
4. **基于证据决策。** 选择证据最充分的机制，并说明其他为何出局。
5. **界定修复范围。** 修复原因，说明影响半径，避免只隐藏症状的改动。

## 危险信号

- 补丁出现在机制被写下来之前。
- 以 catch-all `except:` 作为修复方案。
- 没有引用 evidence_id 的“大概”。
