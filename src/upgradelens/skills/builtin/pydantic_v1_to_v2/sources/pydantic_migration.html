Pydantic V1 → V2 Migration Guide

This is an offline snapshot of the Pydantic migration notes used by UpgradeLens for fixture-based retrieval. It covers the most common breaking changes when moving from Pydantic v1 to v2.

Validators

Validator decorators were renamed and their behaviour changed in v2.

@validator → @field_validator

The @validator decorator is removed in v2. Use @field_validator instead. Validators are now keyword-only and no longer support the pre/each_item positional style in the same way.

from pydantic import BaseModel, field_validator

class User(BaseModel):
    name: str

    @field_validator("name")
    @classmethod
    def normalize(cls, value: str) -> str:
        return value.strip()

@root_validator → @model_validator

@root_validator is replaced by @model_validator. Use mode="before" for the old pre-validation behaviour or mode="after" to validate the whole model.

from pydantic import BaseModel, model_validator

class Account(BaseModel):
    user: str
    password: str

    @model_validator(mode="after")
    def check_passwords(self) -> "Account":
        if self.user == self.password:
            raise ValueError("password equals username")
        return self

Config

Model configuration moved from a nested Config class to the model_config attribute.

Config.orm_mode → from_attributes

The orm_mode = True setting is renamed to from_attributes = True. It still controls whether ORM objects can be read via attribute access.

from pydantic import BaseModel

class UserORM(BaseModel):
    model_config = {"from_attributes": True}
    id: int
    name: str

Serialization

Instance serialization methods were renamed.

.dict() → model_dump()

model.dict() becomes model.model_dump(). The arguments are largely the same.

user = User(name="alice")
data = user.model_dump()

.json() → model_dump_json()

model.json() becomes model.model_dump_json().

user = User(name="alice")
text = user.model_dump_json()

Parsing

Classmethod parsing helpers were renamed.

.parse_obj() → .model_validate()

Model.parse_obj(obj) becomes Model.model_validate(obj). Use model_validate_json for JSON strings.

user = User.model_validate({"name": "alice"})
